HTML-AND-CSS-PROJECTS
Welcome to my HTML and CSS course repository.

ABOUT:
This repository showcases the websites and projects I have built while developing my foundational skills in web design and front-end development. Each project has given me an opportunity to practice creating functional, structured, and visually considered websites while learning how HTML, CSS, and BootStrap work together.

My goal is to continue building on these foundations and develop websites that are not only functional and responsive, but also thoughtful in their design and user experience.


WHAT I AM LEARNING:
Through these projects, I am developing a practical understanding of how websites are structured, styled, and organized. My current focus is on strengthening my HTML and CSS fundamentals, understanding responsive design, learning how to use frameworks such as Bootstrap, and becoming more comfortable with version control and maintaining projects through GitHub.
I am continuing to build on these skills through additional coursework and personal projects, with the goal of creating increasingly polished and user-focused websites.


PROJECTS:

Personal Portfolio Website

A personal portfolio website designed and developed to showcase my web development work, skills, and projects. 
This project brings together the skills I developed throughout my HTML and CSS coursework into a finished personal website. It provides a central place to present my projects and demonstrate my growing abilities in web design and front-end development. The portfolio was designed with a clean, minimalist aesthetic and focuses on presenting my work in a clear and visually engaging way.

Academy Cinemas - Movie Theatre Website

A responsive one-page movie theatre website built with HTML, CSS, and Bootstrap.

This project focuses on creating a structured commercial-style website using Bootstrap components alongside custom CSS. It includes a navigatioin bar, movie information, featured content, contact information, and a multi-column folder.


One-Page Website - Tattoo Portfolio

A minimalist one-page website designed and developed from scratch using HTML and CSS.

This project gave me the opportunity to focus more heavily on visual presentatioin and creating a cohesive design across a single page. It includes navigatioin, multiple content sections, imagery, and interactive hover effects.


Simple Recipes Website

A recipe website created to practice building interactive navigation and organizing different types of content within a website.

This project includes a navigation bar with a dropdown menu, featured recipe content, recipe sections, images, and a contact form. CSS effects and responsive layouts were used to make the site more interactive and adaptable to different screen sizes.


The Pet Shop Website

A multi-page pet shop website created using HTML and CSS.

This project consists of a home page and contact page, with a focus on creating a consistent visual style and organizing website assets into separate files and folders. It helped reinforce the fundamentals of building and styling a website across multiple pages.
