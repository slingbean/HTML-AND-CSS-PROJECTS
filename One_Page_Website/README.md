TATTOO PORTFOLIO WEBSITE

*ABOUT THE PROJECT*
This is a simple one-page tattoo portfolio website created as part of my HTML and CSS coursework.
The purpose of the website is to showcase tattoo artwork in a clean, minimalist layout while practicing the HTML and CSS concepts covered in the course so far.

*FEATURES*
-Navigation menu using HTML bookmarks
-Home section with a title and introduction
-About section with an image and text
-Tattoo portfolio image gallery
-Video section using an embedded video
-Contact form
-Footer

*DESIGN*
The website uses a simple, mostly black-and-white design with neutral tones and plenty of open space. 
The goal was to keep the design minimal so that the tattoo artwork remains the main visual focus.

*TECHNOLOGIES USED*
-HTML5
-CSS3

*WHAT I PRACTICED*
Throughout this project I practiced:
-Creating and organizing HTML sections
-Using headings and paragraphs
-Adding and formatting images
-Creating navigation links with HTML bookmarks
-Creating forms and form inputs
-Embedding video with an iframe
-Using CSS for layout, spacing, typography, and styling
-Organzing a website into a simple, cohesive design

*PROJECT STATUS*
This project was created as a coursework assignment and is not currently intended to be a live website
